# 静默活体检测中的通道剪枝与知识蒸馏

2019–2020 年，我做静默活体检测时，希望把模型放到端侧运行。剪枝决定每个卷积块能用多少通道，蒸馏决定压缩后的学生网络从教师那里学到什么。

## 通道剪枝

我以 MobileFaceNet 为骨干，比较了不同位置的通道宽度。每组配置用 49 个整数描述网络各处的通道数，一个残差块可以占用其中多项。下表按位置对齐这些整数，统计通道数相同、减少和增加的项数。公开的 MiniFASNet 通道表可以用作参照。[MiniFASNet 通道配置](https://github.com/minivision-ai/Silent-Face-Anti-Spoofing/blob/b6d5f04ad78778917853b25c778acef6d5626d15/src/model_lib/MiniFASNet.py#L265)

| 配置对照 | 宽度相同 | 后者更窄 | 后者更宽 |
| --- | ---: | ---: | ---: |
| MiniFASNet V1 → 紧凑配置 A | 31 | 18 | 0 |
| 紧凑配置 A → 紧凑配置 B | 45 | 2 | 2 |

配置 A 集中收窄了 18 项，其余 31 项沿用原宽度。配置 B 又做了一次局部调整，其中两项加宽、两项收窄。这种比较能看出通道具体留在了哪里。要估算计算量，还得看这些卷积对应的特征图尺寸和分组数。

## 知识蒸馏

**类别分布蒸馏（KD）。** 我让教师和学生处理同一批人脸裁剪，用交叉熵让学生学习真实标签，再用 KL 散度让学生逼近教师经温度缩放的类别分布。即使两张图都标成攻击样本，教师也可能只对其中一张给出很高的真人概率。学生能从软标签中学到这种差异。[知识蒸馏论文](https://arxiv.org/abs/1503.02531)

**关系蒸馏（RKD）。** 我还用教师输出向量之间的距离和夹角来训练学生。距离项把同一批次内的样本间距按平均非零间距归一化，角度项衡量以一个样本为参照、指向另外两个样本的方向有多接近。学生用 Smooth L1 损失拟合教师的这两组量。训练时教师只做前向计算，梯度用来更新学生网络。[关系蒸馏论文](https://arxiv.org/abs/1904.05068)
